# MIPS Assembly - COAL Practice & Lab Projects

This repository contains daily practice codes and lab projects from the Computer Organization and Assembly Language (COAL) course.

All codes are written in **VS Code** and tested on **QtSpim** simulator.

## Folder Structure
COAL/

├── projects/

│   ├── mid/                  # Mid-term Lab Project

│   └── terminal/             # Terminal Lab Project

├── *.asm                     # Daily Practice Codes

└── README.md

## Tools Used

- Editor: Visual Studio Code
- Simulator: QtSpim
- Language: MIPS Assembly

## How to Run (QtSpim)

1. Download and install [QtSpim](https://spimsimulator.sourceforge.net/).
2. Open QtSpim.
3. Go to File → Reinitialize and Load File, then select any `.asm` file.
4. Click Simulator → Run / Continue (or press F5) to execute the program.
5. Provide input through the console if required.
