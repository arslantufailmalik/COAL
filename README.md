All programs are written in **VS Code** and tested on **QtSpim** simulator.

## ▶️ How to Run

1. Download & Install **[QtSpim](https://spimsimulator.sourceforge.net/)**
2. Open **QtSpim**
3. Go to `File → Reinitialize and Load File`
4. Select any `.asm` file
5. Click `Simulator → Run / Continue` or press **F5**
6. Enter input in the console if required
